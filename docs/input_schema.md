# Input schema

The analysis repository expects the results directory generated by `architecture-aware-viral-curation`.

Required files by default:

- `tables/02_curated_metadata.xlsx`
- `curated_fasta/all_curated_sequences.fasta`

Required sheets by default:

- `curated_records`
- `component_completeness`
- `component_matrix`

These names may be changed through the YAML configuration.
